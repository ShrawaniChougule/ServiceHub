# 🛠️ ServiceHub

### A Smart Platform for Service Booking and Management

ServiceHub is a web application designed to make it easier for users to access and manage services through a single platform.

## 🌐 Live Demo

**[Visit ServiceHub](https://servicehub-local-ser-il2a.bolt.host)**

## ✨ Features

* User-friendly interface
* Online service access and management
* Responsive web design
* Supabase integration
* Modern frontend built with React and TypeScript

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Vite
* **Styling:** Tailwind CSS
* **Backend/Database Services:** Supabase

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/ShrawaniChougule/ServiceHub.git
```

### 2. Open the project folder

```bash
cd ServiceHub
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file and add the required Supabase configuration variables used by the project.

Do not upload secret keys or private credentials to GitHub.

### 5. Start the development server

```bash
npm run dev
```

## 📦 Production Build

```bash
npm run build
```

The production-ready files will be generated in the `dist` folder.
